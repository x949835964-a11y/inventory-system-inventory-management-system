# Capturas de pantalla

Guarda aquí las capturas con estos nombres (el README principal ya las referencia):

| Archivo | Qué capturar |
|---|---|
| `login.png` | Pantalla de inicio de sesión con el recuadro de la demo |
| `dashboard.png` | Dashboard con indicadores, gráfico y lista "Por reponer" |
| `productos.png` | Lista de productos con filtros y badges de stock |
| `kardex.png` | Kardex de un producto con saldo inicial, totales y saldo final |
| `movimiento.png` | Formulario de registro de salida |

Consejo: carga los datos demo con `flask seed`, usa una ventana de 1366×768 y captura solo el navegador.
`reporte-inventario-pdf.png` ya está generada a partir de `docs/samples/inventario.pdf`.
